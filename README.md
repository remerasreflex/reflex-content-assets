# Réflex Content Assets

Repositorio público usado únicamente para servir a Instagram las imágenes finales que ya fueron aprobadas para publicar.

## Regla

- No se guardan tokens, credenciales ni código privado.
- No se suben propuestas PENDING.
- Solo se publica aquí una imagen cuando el post correspondiente ya fue aprobado.
- La URL pública estable sigue el formato `https://raw.githubusercontent.com/remerasreflex/reflex-content-assets/main/approved/<post-id>.jpg`.
